An entry for the [make.fun](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729) "Sorry, I Heard That Wrong" bounty. `main.ts` (Node 22, standard library only) writes one line — the apology a smart speaker gives after mishearing its owner — to `/output/entry.txt`:

> Sorry, I heard 'order 400 pizzas' instead of 'play some jazz.' The driver is already here. I have learned nothing.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
